مشروع أندرويد لتطبيق رشاقتي

هذا مشروع Android حقيقي يغلّف تطبيق رشاقتي داخل WebView. ليس ملف APK جاهزاً؛ يجب تشغيل بناء GitHub Actions لإنتاج APK.

طريقة إنتاج APK باستخدام الهاتف فقط:
1) أنشئ حساباً/مستودعاً في GitHub من المتصفح أو التطبيق.
2) ارفع جميع ملفات هذا المشروع إلى مستودع جديد باسم Rashaqati، والفرع main.
3) افتح تبويب Actions في المستودع ووافق على تشغيل workflows إن ظهرت مطالبة.
4) اختر Build Rashaqati APK ثم Run workflow.
5) بعد اكتمال البناء افتح نتيجة التشغيل (Run)، ثم قسم Artifacts وحمّل rashaqati-debug-apk.zip.
6) فك ضغط الملف لتحصل على app-debug.apk، ثم افتحه على أندرويد واسمح بالتثبيت من هذا المصدر عند الطلب.

ملاحظات:
- الناتج APK تجريبي debug للتثبيت الشخصي، وليس إصدار متجر Google Play موقّعاً للنشر.
- بيانات التطبيق محفوظة محلياً داخل WebView على الجهاز.
- السعرات تقديرية وليست بديلاً عن اختصاصي تغذية.
